## 2. مصفوفة الإجراءات الوقائية المقسمة زمنياً

### 2.1 إجراءات واجبة التنفيذ فوراً قبل كتابة كود Phase 5 (Pre-Phase 5 Prerequisites):
1. **[أداء]** تطبيق تحرير جلسة قاعدة البيانات قبل استدعاء الـ LLM في `conversational_agent_engine.py`.
2. **[تحصين بالعمق]** تقييد استعلامات القنوات بـ `tenant_id` في عاملي الـ Outbox (`outbox_worker.py:698, 842`).
3. **[حوار]** إلغاء التقطيع التعسفي عند 350 حرفاً وتعديل تعليمات الـ System Prompt التي تمنع التحية في الدور الثاني.

### 2.2 إجراءات تُنفذ بالتوازي مع بناء Phase 5 (During Phase 5 Implementation):
1. بناء نواة محرك الـ StateGraph المحلي المعزول مع جدول نقاط الحفظ `agent_checkpoints`.
2. إنشاء ترحيل Alembic لترقيم استفسارات المالك محلياً وإضافة `tenant_id` للجداول التابعة.
3. تفعيل البحث الدلالي الحقيقي باستخدام pgvector ونموذج تضمين هجين.
